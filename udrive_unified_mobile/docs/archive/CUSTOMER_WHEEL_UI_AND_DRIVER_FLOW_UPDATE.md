# Customer Wheel UI and Driver Flow Update

## Customer dashboard
- Reduced 2-wheel, 3-wheel and 4-wheel selector height and spacing.
- Reduced icon and text size while preserving tap area and readability.
- Search field now uses full available width.
- `View all` is now inside the search field on the right.
- Clear-search icon appears inside the same field only when text exists.

## Driver mode
Drivers do not book their own 2-wheel or 3-wheel vehicle. They:
1. Open Driver mode.
2. Open Vehicle registration / My vehicles.
3. Register Motorcycle/Scooter for 2-wheel, or Auto Rickshaw/Tuk Tuk for 3-wheel.
4. Upload required vehicle documents.
5. Submit for Admin verification.
6. Go online after approval to receive matching Customer requests.

The registration screen now contains explicit 2-wheel and 3-wheel categories and adjusts passenger/luggage defaults automatically.
