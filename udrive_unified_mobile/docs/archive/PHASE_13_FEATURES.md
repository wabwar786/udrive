# Phase 13 Features

- Additive financial ledger and idempotency support.
- Driver wallets with pending, available, and paid balances.
- Automatic net earnings on completed assigned trips.
- Configurable commission rules with default 15% rule.
- Driver payout requests with optimistic concurrency and one-active-request protection.
- Admin payout approval, processing, paid, rejected, failed, and cancelled states.
- Controlled partial/full refund workflow and cancellation-fee storage.
- SuperAdmin financial adjustments with mandatory reason and audit record.
- Finance dashboard, transactions, earnings, wallets, payouts, refunds, and commission-rule views.
- Live Driver earnings screen and payout request using authenticated API data.
