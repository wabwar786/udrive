# UDrive Home Screen Polish Update

## Implemented
- Added proper spacing between 50%/100% booked chips and the From/To booking card.
- Updated Find rides typography and white foreground.
- Applied Montserrat across the app theme using google_fonts.
- Destination history now shows only city chips and filters rides for the next 30 days.
- Removed hero carousel page indicators that overlapped the ride-results heading.
- Ride cards now prioritize destination/location, use a real uploaded vehicle image when available, and fall back to matching local vehicle assets.
- Ride cards show per-seat and whole-vehicle rates.
- Added Book seat and Whole vehicle actions; the detail page opens with the correct booking mode selected.
- Vehicle type filter now opens as a compact right-aligned labelled bar: Car, Bike, Rickshaw, Coster.
- Next-seven-days cards use 80% transparent white backgrounds and show vehicle/type, seats left, per-seat price, and departure date.
- Added image cache sizing and repaint boundaries to reduce unnecessary rendering work.
- Regenerated web and Android app icons from the 1024x1024 UDrive source icon for improved resolution.
