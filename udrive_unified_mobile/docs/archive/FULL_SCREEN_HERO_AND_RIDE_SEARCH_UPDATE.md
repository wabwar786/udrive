# Full-screen Hero and Ride Search Update

- Customer Home now uses a full-screen Kashmir destination image slider.
- Active destination images are loaded from Admin → Destinations.
- Images change automatically every 3 seconds and include a dark readability shade.
- Greeting and customer first name are shown over the hero.
- Active trip card was removed from the Home content.
- Active trip is now accessible from the route icon beside the notification bell.
- Home only shows editable From and selectable To fields over the hero.
- Pickup defaults to the customer's reverse-geocoded current address but remains manually editable.
- Destination opens an inline dropdown of Admin-saved destinations.
- Find rides filters active marketplace rides by selected destination and shows matching results below.
- Customer footer background now uses the same navy/green scheme with no white strip.
- Admin destination image guidance was updated to clearly explain Home hero usage.
