# Customer Home V6 Update

- Removed the duplicate Trip in Progress card below the Find button.
- Kept the active-trip shortcut only in the top bar.
- Added a prominent PICKUP POINT map pin and label.
- Added MapController recentering after GPS location is detected.
- Local mode now immediately lists upcoming local vehicles for the next 30 days.
- Tours mode immediately lists upcoming tour vehicles for the next 30 days.
- Destination typing filters visible vehicles instantly.
- Selecting a Kashmir destination also filters immediately.
- Find button remains available, but destination is no longer required to show the default vehicle list.
- Added compatibility fallback for older API records that do not yet expose a service-type field.
